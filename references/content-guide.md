# 内容口径（孙哥定的规则）

排版和内容解耦：排版只认 `content.json`，所以**文案可以人工审核后随便改**，改完重跑一次即可，版式不会跑偏。

## 一、硬约束

| 规则 | 值 | 怎么核 |
|---|---|---|
| 每条正文字数 | **≤250 字**（含标点、不含空格） | `python scripts/count_chars.py <文件> --limit 250` |
| 板块条数 | 3 条（特殊要求可 4 条） | — |
| 每条段落数 | 1 段（可选 2 段，不要 3 段以上） | — |
| 段落 vs 配图 | 每块 1 张配图 | — |

> 250 字是 2026-09-15 定的：原稿 901 字，孙哥要求压到「每条不超过 250 字」。压缩时**优先保留硬数字**（如 111.5 点、820 元券、293%、3200 亿），砍掉修饰性表述和重复的背景交代。

## 二、品类相关性（很重要）

公司主营 **儿童用品 / 童装**，另有 **跨境电商（亚马逊、欧美市场、儿童睡袋）**。

放进简报的内容必须与这些相关。**不相关品类直接删**：
- 家电数码国补、3C 换新补贴之类的品类不相关 → 不写
- 成人服饰大盘、汽车、房产 → 不写

## 三、平台白名单

**主营**：抖音、天猫、拼多多。**次要**：京东、唯品会。
**跨境**：亚马逊（美国站 / 欧洲站）。

**不写的平台**：速卖通、快手、Temu、Shopee 等（与公司渠道无关）。
> 注：若某期要做行业风向而非平台动态，另议；默认按白名单。

## 四、每条只讲一个立意

不要堆砌信息。例：

- 第一条的立意 = **「消费节奏已经拉起来了」**：物流指数先动 → 各平台把中秋档铺满 → 双11 预热接上，节点首尾相接。
- 第三条的立意 = **「备货与合规要同时交卷」**：Q4 档期与费用 + 睡袋安全标准收紧。

定稿后应该能用一句话说出这条在讲什么。说不出来就是信息堆砌，要重写。

## 五、文风

- **密集、带数字、陈述句**，不写评论口吻
- 段末可以引一句判断，用「业内认为…」「业内观察认为…」
- 小标题格式 `主题词｜正标题`
- 往期用过的主题词：`报告解读` / `电商大促` / `平台动向` / `趋势洞察` / `营销风向` / `规则风向` / `跨境电商`

## 六、检索方向

每期跑这几条线（`WebSearch`，`freshness: d10` 左右）：

1. **平台大促节奏**：天猫 / 拼多多 / 京东 / 唯品会 / 抖音商城 的大促档期、招商、玩法（只跑白名单平台）
2. **抖音电商玩法与营销风向**：商城活动、直播玩法、商家经营模式变化
3. **跨境电商**：亚马逊欧美站的档期、费用政策、合规新规、母婴/儿童用品类目门槛（睡袋安全标准尤其要跟）
4. **行业趋势**：童装/母婴市场规模、功能化面料、文化元素、校服/亲子装赛道
5. **合规风向**：平台规则、监管新规（只取与母婴童装相关的口径）

常用来源：中服协、织里童装城、中童传媒、网经社、电商日报、亿邦动力、亚马逊卖家平台公告。

## 七、流程要求

1. **先列新闻清单**（含来源与关键数字）→ 给孙哥确认 → 才动手排版。不能跳过。
2. 确认口径用一次 AskUserQuestion 问清：收录条数 / 配图方式 / 刊期日期。
3. 配图用 AI 生成前要**先告知额度消耗**。
4. 定稿后直接落地，不要反复讨论。
