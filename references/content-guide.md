# 内容口径（孙哥定的规则）

排版和内容解耦：排版只认 `content.json`，所以**文案可以人工审核后随便改**，改完重跑一次即可，版式不会跑偏。

## 一、硬约束

| 规则 | 值 | 怎么核 |
|---|---|---|
| 每条正文字数 | **≤250 字**（含标点、不含空格） | `python scripts/count_chars.py <文件> --limit 250` |
| 板块条数 | **2–4 条**（当期选题时定，默认 3） | — |
| 每条段落数 | 1 段（可选 2 段，不要 3 段以上） | — |
| 段落 vs 配图 | 每块 1 张配图 | — |
| 主题词 | 取自当期选定的领域（`assets/topics.json`） | 见 `topic-menu.md` |

> 250 字是 2026-09-15 定的：原稿 901 字，孙哥要求压到「每条不超过 250 字」。压缩时**优先保留硬数字**（如 111.5 点、820 元券、293%、3200 亿），砍掉修饰性表述和重复的背景交代。

## 二、品类相关性（很重要）

公司主营 **儿童用品 / 童装**，另有 **跨境电商（亚马逊、欧美市场、儿童睡袋）**。

放进简报的内容必须与这些相关。**不相关品类直接删**：
- 家电数码国补、3C 换新补贴之类的品类不相关 → 不写
- 成人服饰大盘、汽车、房产 → 不写

## 三、平台白名单

**主营**：抖音、天猫、拼多多。**次要**：京东、唯品会。
**跨境**：亚马逊（美国站 / 欧洲站）。

**不写的平台**：速卖通、快手、Temu、Shopee 等（与公司渠道无关）。
> 注：**只要涉及平台就按白名单**。若本期选的是不绑平台的领域（如行业趋势、政策与宏观、
> 供应链与产业带），白名单自然用不上，不必硬凑。

## 四、每条只讲一个立意

不要堆砌信息。**立意跟着当期选定的领域走，不预设**。定稿后应该能用一句话说出这条在讲什么，
说不出来就是信息堆砌，要重写。

举例（第 38 期的两条，仅作风格参考，**不是固定模板**）：

- 立意 = **「消费节奏已经拉起来了」**：物流指数先动 → 各平台把中秋档铺满 → 双11 预热接上，节点首尾相接。
- 立意 = **「备货与合规要同时交卷」**：Q4 档期与费用 + 睡袋安全标准收紧。

> 早期这里写死了「第一条讲消费节奏、第三条讲备货合规」，结果每期都长一个样。
> 现在立意由当期选题决定，见 `topic-menu.md`。

## 五、文风

- **密集、带数字、陈述句**，不写评论口吻
- 段末可以引一句判断，用「业内认为…」「业内观察认为…」
- 小标题格式 `主题词｜正标题`
- **主题词取自当期选定的领域**，完整可选清单在 `assets/topics.json`（14 个），怎么选用见 `topic-menu.md`
- 往期用过的主题词：`报告解读` / `电商大促` / `平台动向` / `趋势洞察` / `营销风向` / `规则风向` / `跨境电商`
  （其中 `报告解读`、`趋势洞察` 已归入「行业趋势」，`规则风向` 已归入「平台动向」）

## 六、检索方向：由当期选题决定

**不再有固定的几条线。** 每期先走选题环节（见 `topic-menu.md`）定下要覆盖哪几个领域，
然后**只按选定领域**去搜。

`assets/topics.json` 里每个领域都给了 4–6 个检索关键词和常用来源，直接拿来跑 `WebSearch`
（`freshness: d10` 左右）。每个领域 2–3 条查询即可。

跨领域常备来源：中服协、织里童装城、中童传媒、网经社、电商日报、亿邦动力、亚马逊卖家平台公告。

> 旧版在这里列了「①平台大促节奏 ②抖音电商玩法 ③跨境电商 ④行业趋势 ⑤平台合规」这 5 条固定线，
> 每期照跑，是内容框死的根源，2026-09-15 撤掉。

## 七、流程要求

1. **先选题**：跑 `scripts/topic_menu.py` 生成候选 → 一次 `AskUserQuestion` 问清
   本期覆盖哪些领域 / 收几条 / 有没有特别想跟的方向。详见 `topic-menu.md`。
2. **定向检索**：只按选定领域的 `keywords` 搜，整理成候选新闻清单。
3. **列清单确认**：把清单（含来源与关键数字）给孙哥过目 → 确认收录哪几条 / 配图方式 / 刊期日期。
   不能跳过。
4. 配图用 AI 生成前要**先告知额度消耗**。
5. 定稿后直接落地，不要反复讨论。
